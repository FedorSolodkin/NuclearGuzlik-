# Стенд чувствительности VAD

Исследование «автоматической настройки чувствительности»: как выбирать параметры
Silero VAD перед Whisper, чтобы терять меньше речи и не кормить Whisper шумом.
Стенд прогоняет записи через **тот же конвейер, что приложение**, на компьютере.

## Что такое «чувствительность» в VoiceMind

Микрофон пишет всё (`VOICE_RECOGNITION`, без автоусиления). При расшифровке каждый
кусок записи (40–58 с) проходит Silero VAD внутри whisper.cpp: Whisper получает
только участки, признанные речью. Чувствительность — параметры этого VAD: порог
вероятности речи и запас вокруг найденной речи.

## Воспроизведение

```bash
# 1. Модели — те же файлы, что в приложении (проверить SHA256 по ModelIntegrity.kt)
mkdir -p ~/voicemind-bench/models   # ggml-whisper-podlodka-turbo-q4_0.bin, ggml-silero-v6.2.0.bin

# 2. Сборка (whisper.cpp из submodule с нашими патчами, CPU хоста)
cmake -S tools/vad_bench -B ~/voicemind-bench/build -DCMAKE_BUILD_TYPE=Release -DGGML_NATIVE=ON
cmake --build ~/voicemind-bench/build -j --target vmbench

# 3. Данные: Golos (crowd + farfield validation, HF bond005/…) → ~/voicemind-bench/data/golos,
#    шумы MS-SNSD → data/noise/{tune,eval}; затем
python3 -m venv ~/voicemind-bench/.venv && ~/voicemind-bench/.venv/bin/pip install numpy scipy pyarrow num2words
~/voicemind-bench/.venv/bin/python gen_synth.py

# 4. Эксперименты
python exp_frames.py synth/tune baseline        # кадровые метрики, без Whisper (секунды)
python exp_wer.py run    synth/tune base pad300 gate58
python exp_wer.py report synth/tune base pad300 gate58
```

## Файлы

| Файл | Что |
|---|---|
| `vmbench.cpp` | процесс-сервер: модель грузится один раз; команды `probs`, `segs`, `asr`, `autothr` |
| `bench.py` | конвейер приложения (нарезка, промпт, HallucinationFilter), порт сегментации VAD, метрики, кэш |
| `gen_synth.py` | синтетические разговоры с разметкой речи |
| `exp_frames.py` | кадровые метрики VAD: пропуск речи / ложная речь по условиям |
| `exp_wer.py` | ошибки по словам + парный бутстреп |
| `../../app/src/main/cpp/auto_vad.h` | автопорог — **один код** для приложения и стенда |

Проверки соответствия приложению:
- python-порт сегментации = `whisper_vad_segments_from_probs`: 280/280 конфигураций совпали;
- автопорог в C++ (код приложения) = python-стратегия: 64/64 куска, расхождение < 1e-4;
- стенд на записи с телефона выдал текст слово в слово как приложение.

## Данные

**Синтетика** (`gen_synth.py`): сессии ~80 с из фраз Golos с паузами 0.3–2.5 с и одной
длинной паузой 5–12 с. Уровни откалиброваны по записи с телефона (речь вблизи ≈ −20 dBFS,
фон комнаты ≈ −44 dBFS):

- говорящие: near −20 dBFS (Golos crowd), mid −30 и far −40 dBFS (Golos farfield — настоящая
  дальняя речь с реверберацией);
- шум: silent −60 (белый), room −45, office −35, loud −28 dBFS (MS-SNSD: кондиционер, кафе,
  офис, транспорт, клавиатура…; файлы с чужой речью исключены);
- 4 набора говорящих × 4 уровня шума × 2 = 32 сессии на split.

**tune / eval** — разные фразы (по хэшу звука) и разные файлы шума. Всё подбиралось на tune;
eval использован один раз, для финальной проверки с заранее зафиксированными параметрами.

Разметка речи по кадрам — по чистому сигналу фразы: кадр «голос», если не тише активного
уровня фразы на 25 дБ и на 10 дБ громче её собственного фона (у Golos свой фон).

## Метрики

- **WER** по нормализованному тексту (регистр, ё→е, пунктуация, числа → слова), отдельно
  пропуски / вставки / замены. Пропуск дороже: потерянная речь не восстанавливается.
- **Секунды в Whisper** — на телефоне Whisper ~3× медленнее реального времени
  (SD732G: 324 с на 100 с аудио), так что лишнее аудио = заметное ожидание.
- **Значимость** — парный бутстреп по сессиям (10 000 повторов), 95% ДИ разницы WER.

## Результаты (tune, 32 сессии, 2299 слов)

| Конфигурация | WER | пропуски | вставки | в Whisper, с | Δ к текущему |
|---|---|---|---|---|---|
| текущий: порог 0.5, запас 30 мс | 44.7 | 30.8 | 1.0 | 924 | — |
| «Тихо» 0.35 | 43.1 | 29.8 | 1.2 | 983 | −1.6 [−3.3, +0.3] |
| «Шумно» 0.64 | 46.6 | 33.0 | 1.2 | 878 | +2.0 [+0.4, +3.5] |
| запас 150 мс | 41.5 | 29.1 | 1.5 | 1031 | −3.1 [−5.0, −1.3] |
| **запас 300 мс** | **39.0** | 26.1 | 1.5 | 1139 | **−5.7 [−8.6, −3.2]** |
| запас 500 мс | 39.5 | 25.7 | 1.4 | 1271 | −5.4 [−8.6, −0.9] |
| без VAD | 39.1 | 20.7 | 2.3 | 2492 | −5.7 [−9.0, −2.0] |
| адаптивный порог без ворот | 37.9 | 23.8 | 2.1 | 1333 | к pad300: −1.1 [−3.5, +1.6] |
| **адаптивный с воротами (gate58)** | **37.4** | 23.5 | 1.6 | 1199 | **к pad300: −1.5 [−3.2, −0.2]** |

Минимальная пауза (100 / 300 / 600 мс) на результат не влияет.

**Выводы.**
1. Главная причина потерь — не порог, а запас 30 мс: VAD срезал края слов. Запас 300 мс —
   оптимум (500 не лучше, а аудио больше).
2. С запасом 300 мс VAD по точности = «без VAD», но отдаёт Whisper в 2.2 раза меньше аудио;
   в тишине VAD даже точнее (Whisper не выдумывает текст на паузах).
3. Silero хорошо отделяет речь от шума (AUC 0.90–0.99 во всех условиях, кроме дальней речи
   на 12 дБ тише шума — AUC 0.56, это не спасти), но **лучший порог зависит от фона**:
   ~0.05 при ровном шуме (офис), ~0.5 при шуме, похожем на речь (кафе). Отсюда адаптивный порог.
4. **Ворота обязательны.** Без них в тишине порог падал до 0.1, в Whisper шли паузы, окно 30 с
   становилось «пустым», и защита Whisper (`no_speech_thold`) выбрасывала его вместе с фразами
   (тишина: WER 20.3 → 24.3). С воротами (фон тише −58 dBFS → 0.5) этого нет.
5. Потолок: оракул (лучший порог для каждой сессии) — 35.0; gate58 берёт ~40% от возможного.

## Ограничения

- Golos — короткие команды (~5 слов): срез одного слова весит больше, чем в разговоре.
  Эффект запаса на живой речи, вероятно, меньше. **Нужна проверка на реальных записях**
  (`data/real/scripts.md` — сценарии и тексты).
- Язык фиксирован ru (определение языка не исследовалось; в «Авто» для него берётся 0.5).
- Разметка дальней речи (farfield) менее точна: у исходных записей свой фон.
- Уровни фона в синтетике заданы классами; ворота −58 dBFS подобраны на них и должны быть
  перепроверены на реальных записях телефона.
- Диаризация использует свой энергетический VAD (порог RMS 150) — вне этого исследования.
