# Требования задания: как закрыто

Источник: PDF организаторов «Хахатон Ноябрь 2026», слайды 8–22. Структура репозитория повторяет
[grigorevmp/hacathon_template](https://github.com/grigorevmp/hacathon_template): `src`, `config`, `docs`, `artifacts`.

Статусы: **есть** (реализовано и проверено), **есть, не измерено** (реализовано, цифры качества нет),
**частично**, **нет**. Доказательства указаны файлами в репозитории. Если цифры нет, это сказано прямо.

## Обязательные требования (слайд 9)

| Требование | Статус | Как сделано | Доказательство |
|---|---|---|---|
| Android OS | есть | Kotlin-приложение, `minSdk 26`, ARM64, пакет `ru.guzlik.voice.hackathon` | `artifacts/apk/manifest.json` |
| Локальная LLM | есть | Gemma 2 2B (ru90k, GGUF Q4_K_M) через llama.cpp на устройстве: «Выделить главное» и вопросы к записи. В расшифровку и JSON LLM не вмешивается | `config/contest-models.json`; вопрос к Gemma прошёл на Xiaomi за 14,5 с (`artifacts/test-results/contest-bundled-apk.json`) |
| Импорт аудио из памяти | есть | Системный выбор файла (SAF), декодирование Android MediaCodec в PCM 16 кГц mono на диск | Прогон `r002.wav` на эмуляторе, `results.csv` |
| Речь в текст | есть | GigaAM v3 RNNT int8 с пунктуацией (sherpa-onnx), речь режется Silero VAD; только русский | Текущая сборка на Xiaomi: ASR RTF 0,19–0,24 на 3 коротких записях (`rnnt-only-phone-2026-11-08.md`). WER финальной сборки на `test_data/real` и синтетике **не измерен**. Прежняя сборка (Whisper) на эмуляторе: 5,6% синтетика, 19,7% живые (`results.csv`); сравнение движков: `whisper-vs-gigaam-pr14.md` |
| Автоматическое определение говорящих | есть, качество неровное | pyannote segmentation 3.0 + WeSpeaker ResNet34 (ONNX), кластеризация и уточнение границ на Kotlin; запускается сама после расшифровки, число людей определяется само | Текущая сборка: DER 1,5% (5 с, 1 голос) и 3,2% (34 с, 2 голоса) на публичной TTS-записи, Xiaomi (`rnnt-pipeline-2026-11-08.md`). Прежняя сборка, 27 синтетических диалогов: DER среднее 34,8%, число говорящих верно в 9 из 27 (`results.csv`). Прошлая версия на компьютере: [diarization-audit](../artifacts/test-results/diarization-audit-2026-11-06.md) |
| Временные метки реплик | есть | Пословные времена из меток токенов GigaAM и границы голосов; в JSON `start_ms`, `end_ms` | Юнит-тесты экспорта; ограничение точности: [LIMITATIONS.md](LIMITATIONS.md) |
| Отображение расшифровки | есть | Карточка записи: реплики по говорящим, имена, редактирование текста | Скриншоты `artifacts/demo/screens/`; видео ещё не выложено |
| Экспорт в файл | есть | Кнопка «Экспорт JSON», файл в «Загрузки» (также автоматически после обработки), «Поделиться» | Контракт: [PROTOCOL.md](PROTOCOL.md); 252 юнит-теста. Прежняя сборка: экспорт отказал на 5 из 35 файлов («Нулевая длительность реплики»), 30 экспортов в `artifacts/test-results/exports/`; в текущей сборке экспорт не отменяется (запасной режим), повторный прогон на финальной APK предстоит |

## Ограничения обработки (слайды 10–11)

| Ограничение | Статус | Как соблюдено |
|---|---|---|
| Не передавать аудио внешним сервисам, нет облачных API | есть | Все модели внутри APK, инференс на устройстве (ONNX Runtime, llama.cpp через JNI) |
| Нет вычислений на удалённом сервере или компьютере | есть | Компьютерные инструменты в `scripts/` и `src/android/tools` только для оценки качества, в обработке конкурсного аудио не участвуют |
| Не подменять работу модели готовой расшифровкой | есть | Эталоны лежат только в `test_data/` как данные проверки, приложение их не читает |
| Работа без интернета, модели на устройстве | есть | Модели извлекаются из APK при первом запуске; проверено в авиарежиме на Xiaomi и на эмуляторе |

## Формат вывода (слайды 14–15)

| Пункт | Статус | Доказательство |
|---|---|---|
| `transcript[]`, `speaker_id` (string), `start_ms`, `end_ms` (int), `text` | есть | [PROTOCOL.md](PROTOCOL.md), `scripts/evaluate.py` проверяет контракт |
| Неопределённость не выдумывается | есть | Идентификаторы `unknown` и `overlap` |

## Базовый уровень (слайд 17)

Все семь пунктов закрыты: APK, импорт, локальная LLM, ASR, диаризация, метки, отображение и экспорт (см. таблицу выше).

## Средний уровень (слайд 18)

| Пункт | Статус | Как сделано / граница |
|---|---|---|
| Предварительная обработка аудио | частично | Декодирование и приведение к 16 кГц mono; отдельного шумоподавления нет |
| Фильтрация пауз и неречевых фрагментов | есть | Silero VAD (окна 512 отсчётов). Известный риск: у Whisper-сборки на «телефонной» записи агрессивный порог VAD выбрасывал слова (host-wer-comparison.md); для GigaAM не перемерено |
| Устойчивое определение участников при смене реплик | есть, не измерено | Уточнение границ (`SpeakerBoundaryRefiner`), повторная кластеризация. Ошибки числа людей на коротких репликах и похожих голосах остаются |
| Восстановление пунктуации | частично | Знаки и заглавные даёт сама GigaAM v3 (вариант с пунктуацией); отдельной модели нет. Строгий WER со знаками и регистром у GigaAM на 3 записях 46,4% против 47,5% у Whisper (`whisper-vs-gigaam-pr14.md`) |
| Отображение прогресса | есть | Прогресс ASR и диаризации в процентах и в уведомлении |
| Воспроизведение с переходом к реплике | есть | Плеер в карточке записи, переход по времени |

## Ultra Pro Max (слайд 19)

| Пункт | Статус | Как сделано / граница |
|---|---|---|
| Фоновый шум и плохие записи | частично | VAD + GigaAM; измерения шума только на прежней сборке (Whisper): синтетика с шумом WER 4,7–15,4% (d027 15,4%); дальний микрофон AMI: DER 31,11% (прошлая версия, компьютер) |
| Короткие реплики и перебивания | частично | Окна коротких реплик и уточнение границ; ошибки остаются, см. LIMITATIONS |
| Одновременная речь | частично | Обнаруживается и помечается `overlap`; разделение смеси на голоса **не реализовано** |
| Разный тембр и манера речи | не измерено | Сравнение на разных голосах: только синтетика (один синтезатор) и 4 живые записи |
| Оптимизация RAM | есть | Аудио на диске (`FilePcm`) вместо RAM, обработка кусками, сериализация тяжёлых заданий |
| Ускорение за счёт железа | частично | Vulkan подгружается динамически, на неподдерживаемом устройстве CPU; выигрыш не на каждом устройстве |
| Редактирование и повторная обработка фрагментов | частично | Редактирование текста и повторное разделение по голосам есть; повторное распознавание произвольного фрагмента **не реализовано** |
