# Ограничения

- Автоматическое число людей ошибается, особенно на коротких ответах и похожих голосах.
- Детекция overlap не разделяет смесь на отдельные чистые голоса. Текст каждого
  из одновременно говорящих не гарантируется.
- Дальний микрофон AMI в предыдущем компьютерном тесте дал DER 31,11% и ошибку
  числа участников. Шумоподавление как отдельный гарантированный этап не заявлено.
- Пословные таймкоды Whisper приблизительные. Экспорт по старым фразовым временам
  и после ручных правок менее точен; детали в PROTOCOL.md.
- Повторная диаризация записи использует кеш. Выборочная ASR-переобработка произвольного
  выделенного пользователем интервала пока не реализована в конкурсном интерфейсе.
- Для LLM нужны RAM и свободный диск; скорость, нагрев и RTF новой APK на устройстве
  должны быть измерены отдельно. Vulkan быстрее не на каждом устройстве.
- Модели устанавливаются заранее. Чистая установка APK без моделей не готова к
  офлайн-проверке. При загрузке моделей интернет требуется; аудио туда не отправляется.
- Приложение унаследовало необязательные календарные и клиентские интеграции.
  В конкурсном сценарии их не подключают; авиарежим проверяет независимость обработки.
- APK разработки подписана debug-ключом и предназначена для проверки, не для магазина.
- Видео новой версии и сквозной тест на подключённом Android ещё требуются.
