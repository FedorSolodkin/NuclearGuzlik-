# Контракт JSON

UTF-8, MIME `application/json`, верхний объект содержит только `transcript`.
Каждая реплика содержит ровно четыре поля:

| Поле | Тип | Смысл |
|---|---|---|
| speaker_id | string | speaker_1, speaker_2 и т.д.; стабильный индекс найденного голоса |
| start_ms | integer | начало относительно начала импортированного аудио |
| end_ms | integer | конец, строго больше начала |
| text | string | текущий текст реплики, включая ручные правки |

`unknown` означает отсутствие уверенной личности, `overlap` — одновременную речь.
Схема задания требует string и не ограничивает словарь ID. Экспорт не выполняет
source separation и не создаёт две достоверные расшифровки из одного наложения.
Сравнение с эталонами должно учитывать неопределённость, а не удалять эти строки.

Реплика здесь — блок текущего текста до следующей метки говорящего. Несколько
последовательных фраз одного голоса могут быть одним блоком. Границы берутся
по первому и последнему совпавшему ASR-слову; в старых записях без слов — по
фразовым временам. Для ручных вставок отдельного акустического времени нет:
сохраняется текст, время блока определяется оставшимися якорями. Полностью
переписанный блок без совпадений не экспортируется: предлагается повторная обработка.
Это приближённое выравнивание, его нельзя считать новым forced alignment.

Неоднозначные одинаковые имена, удалённые метки нескольких говорящих, отсутствующая
диаризация и некорректные времена вызывают ошибку вместо выдачи выдуманных данных.
Пустой диалог после завершённой диаризации может иметь пустой массив.

```bash
python3 scripts/evaluate.py exported.json --reference reference.json --elapsed-seconds 42 --audio-seconds 60
```
