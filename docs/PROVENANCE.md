# Происхождение

Исходная разработка: VoiceMind, репозиторий FedorSolodkin/VoiceMind,
локальная ветка `codex/android-full-user-flow-audit`, commit
`04b1e9a` (полный SHA в config/source.json). В основу взят текущий чистый снимок
Android-кода с накопленными улучшениями. История личной рабочей папки, Android
SDK, ключи подписей, сервер подписок, Meet, записи пользователей и модели сюда
не перенесены. Android-код включает существующее направление wearable;
оно не используется для конкурсной обработки импортированных файлов.

Это не заявление, что приложение целиком написано во время хакатона.
Условия допустимости ранее созданного кода нужно согласовать с организаторами.
В предоставленном PDF разрешены готовые модели и библиотеки; отдельного явного
разрешения на ранее созданный продукт там нет.

whisper.cpp и llama.cpp закреплены как submodule upstream. Локальные изменения
C++ применяются из patches при сборке. Условия моделей и сторонних библиотек
сохраняются; приватность репозитория не отменяет их. Условия Gemma:
`src/android/scripts/mirror/GEMMA-NOTICE.txt`.
