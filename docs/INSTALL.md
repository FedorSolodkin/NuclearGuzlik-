## Подготовка до оценки

Установите APK из artifacts/apk. Пакет `ru.guzlikvoice.app.hackathon` устанавливается
рядом с обычной GuzlikVoice и не использует её записи или ранее скачанные модели.

Откройте приложение с интернетом, скачайте модель распознавания «Точно», голоса
и детекторы речи. В настройках установите Gemma 2 2B; не пропускайте LLM перед
проверкой. pyannote нужен для лучшей обработки смены голосов и overlap.
Модели и контрольные суммы перечислены в [config/models.json](../config/models.json).

Альтернатива: на компьютере из корня репозитория выполните:

```bash
python3 scripts/prepare_models.py
python3 scripts/prepare_models.py --verify-only
```

Скрипт скачивает только веса и проверяет SHA-256; аудиозаписи он не читает.
Нужен запас диска не менее 4 ГБ. Либо заранее скачайте файлы с указанных URL, сверьте SHA-256 и импортируйте
через настройки → установка модели из файла. Узнавание файлов происходит по SHA-256,
а не по имени. Для первого запуска без сети можно скопировать модели через ADB:

```bash
adb install artifacts/apk/GuzlikVoice-hackathon.apk
# Откройте приложение один раз, чтобы Android создал каталог.
adb shell mkdir -p /sdcard/Android/data/ru.guzlikvoice.app.hackathon/files
# В папке config/models файлы должны называться как device_name из models.json.
adb push config/models/. /sdcard/Android/data/ru.guzlikvoice.app.hackathon/files/
```

Если выбран вариант с ADB, до запуска проверки убедитесь, что все модели видны
в настройках и загружаются. Вспомогательные файлы и пути не заменяют проверку модели.

## Три неизвестные записи

1. Включить авиарежим, отключить Wi-Fi.
2. Импортировать первую локальную запись, запустить ASR, затем автоматическую диаризацию.
3. Прослушать несколько реплик по меткам времени, проверить смены говорящих.
4. Запустить «Выделить главное» и задать вопрос по записи для демонстрации LLM.
5. Экспортировать JSON, сохранить отдельно. Повторить для второй и третьей записи.
6. Засечь wall-clock время от запуска обработки до готовности диаризации. Для RTF
   делить секунды обработки на длительность аудио в секундах; импорт и LLM измерять
   отдельно. Зафиксировать устройство, RAM, версии APK и моделей, CPU/GPU и условия нагрева.
7. Проверить JSON валидатором scripts/evaluate.py и сравнить с независимыми эталонами.

Время ручной проверки не включается в RTF. Не использовать подготовленный текст
вместо реального инференса. При ошибке сохранять исходный экспорт и описание сбоя.
