# Тестовые данные

`real/` — эталоны текста и говорящих для четырёх живых записей (`real/audio/r001.wav` … `r004.wav`,
согласие говорящих на публикацию получено). Формат файлов в `real/ref/` — формат задания:
`{"transcript":[{"speaker_id","start_ms","end_ms","text"}]}`. `real/meta.jsonl` — те же реплики для `scripts/evaluate.py`-подобных
подсчётов. Что именно поправлено и что оставлено неопределённым: [real/CHANGES.md](real/CHANGES.md).

Ограничения: тексты размечены человеком по исходным машинным черновикам; у r003 и r004 границы реплик остаются машинными
(годятся для WER, но не для проверки точности временных меток); в r002 пять реплик с говорящим `unknown`.
Синтетический набор (озвученные диалоги с точной разметкой времени) в репозиторий не включён из-за размера.
