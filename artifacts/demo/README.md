## Сценарий на 3–5 минут

1. Версия APK и установленные модели (экран «Подготовка к работе», настройки).
2. Включить авиарежим, показать значок в строке состояния.
3. «Расшифровать аудиофайл», выбрать неизвестный диалог.
4. Прогресс расшифровки, затем автоматического разделения по голосам (уведомление и карточка).
5. Реплики по говорящим, прослушать смену голосов, исправить слово.
6. «Выделить главное» или вопрос к записи: локальная Gemma.
7. «Экспорт JSON»: показать файл в «Загрузки» и четыре поля реплики.
8. Известный сложный случай и ограничения: [../../docs/LIMITATIONS.md](../../docs/LIMITATIONS.md).

## Как записывать

```bash
adb shell screenrecord --time-limit 180 /sdcard/demo1.mp4   # части по 3 минуты (лимит команды)
adb pull /sdcard/demo1.mp4
adb exec-out screencap -p > artifacts/demo/screens/01-models.png
```
