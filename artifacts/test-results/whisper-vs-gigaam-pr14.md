# Сравнение Whisper и GigaAM на эмуляторе (PR #14)

Источник: описание [PR #14](https://github.com/FedorSolodkin/NuclearGuzlik-/pull/14) («GigaAM v3 как второй ASR-движок»). Перенесено сюда, чтобы цифры были в репозитории.

**Важная оговорка.** Замер сделан на варианте GigaAM v3 **CTC** (sherpa-onnx, с пунктуацией), а не на финальном **RNNT**, который стоит в конкурсной APK.
Числа ориентировочные для выбора движка, а не результат финальной сборки. Эмулятор Android (4 потока, авиарежим), живые записи r001, r002, r004
(у Whisper на r003 не собрался JSON, дефект экспорта прежней сборки). Три записи, без доверительных интервалов; синтетический набор не прогонялся.

| Показатель | Whisper podlodka | GigaAM v3 (CTC) |
|---|---|---|
| RTF распознавания | 0,59–0,67 | 0,06 |
| RTF «файл → JSON» | 0,9–1,3 | 0,14–0,19 |
| Пик памяти | 1,86 ГБ | 0,74 ГБ |
| WER по словам | 19,7% | 17,9% |
| WER строгий (знаки и регистр) | 47,5% | 46,4% |
| JSON с несколькими `speaker_id` | не указано | 4 из 4 |

Известные недостатки, указанные в PR: теряется первое слово реплики из-за позднего старта VAD; на r002 диаризация давала один голос.

Для сравнения на компьютере (без VAD, 4 живые записи и 31 синтетический диалог) см. [host-wer-comparison.md](host-wer-comparison.md).
Цифры Whisper по прогону 35 файлов на прежней сборке: `results.csv`, строки `apk-*`.
